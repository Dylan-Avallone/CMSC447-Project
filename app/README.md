# Library Dashboard System

## Purpose
This project is a library dashboard system that is meant to display and manage library data in a simple, organized way. The goal is to build a basic full-stack application with a frontend, backend, and SQL database.

## Frontend
The frontend is built with **Streamlit**. It is responsible for displaying the dashboard interface, including tables, charts, and other visual elements the user interacts with.

## Backend
The backend is planned to use **FastAPI**. It will handle application logic, connect to the SQL database, and send data to the frontend.

## Tech Stack
- Python
- Streamlit
- FastAPI
- SQL Database
